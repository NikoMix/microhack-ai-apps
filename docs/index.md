# Zava AI MicroHack

Welcome to the **Zava AI MicroHack** — a **1-day, instructor-led, Train-the-Trainer** course where
you build a **multi-agent AI application on Microsoft Azure** using the **Microsoft Agent Framework**,
and produce **audit evidence** for the *AI Applications on Microsoft Azure* **Advanced Specialization
(Module B)** as a by-product.

!!! tip "Two tracks, one story"
    Choose **Python** or **.NET (C#)** — both build the same agents, expose the same HTTP API, and
    follow the same labs. Every AI call runs on **GitHub Models** (free) or **Azure** via one config
    switch.

## The story

[Zava](overview.md) is an *intelligent athletic apparel* retailer. Its platform team (you) is rolling
out an **AI Agent Platform**: cooperating agents that help customers, merchandisers, and operations
staff — all governed by a **trust & compliance** agent that also assembles the partner's audit
evidence package.

## What makes this microhack different

- **Latest agentic stack** — Microsoft Agent Framework, GitHub Copilot custom agents, Copilot skills,
  and **MCP servers** (including a bespoke Zava MCP server).
- **Modular inference** — GitHub Models / Azure OpenAI / Azure AI Foundry, swappable by config.
- **Free to start** — Labs 0–2 cost nothing (GitHub Models); Azure begins at Lab 3.
- **Evidence-as-you-go** — each lab emits artifacts that satisfy Advanced Specialization controls.
- **OSS only** — no paid licenses anywhere.
