## Using these files

Each talk-track file contains:

- **Lecture notes** — key points to land during the lecture slot, in order
- **Demo cues** — specific commands or screen actions to show live
- **Lab facilitation notes** — what to watch for, common blockers, expected outcomes
- **Evidence checkpoint** — the artifact produced and the Module B control it satisfies
- **Common questions** — answers to the questions most frequently asked during delivery
